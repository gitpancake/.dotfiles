# iTerm2 Color Schemes

Gruvbox Material presets, sourced from [iTerm2-Color-Schemes](https://github.com/mbadolato/iTerm2-Color-Schemes).

## Files
- `GruvboxMaterialDark.itermcolors`
- `GruvboxMaterialLight.itermcolors`

## Install
```sh
open GruvboxMaterialDark.itermcolors
open GruvboxMaterialLight.itermcolors
```

Then iTerm2 → Settings → Profiles → Colors → Color Presets → pick `Gruvbox Material Dark` or `Gruvbox Material Light`.
